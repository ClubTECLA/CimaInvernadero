# Base de datos

Esta carpeta contiene el esquema SQL de la aplicación. Ahí se describen los datos de ubicaciones, zonas, nodos, sensores, lecturas y automatizaciones.

El backend aplica los cambios de estructura al iniciar. Los datos de demostración, cuando se habilitan en el entorno, sirven para revisar la interfaz y no representan mediciones de sensores reales.

Para el mapa general de la aplicación, consulta [Contexto de la aplicación](../docs/CONTEXTO_APLICACION.md). Para el flujo de gateways, consulta el [contrato de API](../docs/API_GATEWAY_V1.md).
